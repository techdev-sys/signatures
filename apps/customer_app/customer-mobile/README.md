# Paramount Signature

Expo SDK 58 app for the Paramount Signature restaurant and bar concept. The app opens the complete mobile ordering experience, including the food and drinks menu, branch selection, collection or delivery, demo checkout, order tracking, and branch/driver preview workspaces. Menu prices and order/payment behavior remain illustrative and local to the device.

## Start the app

From this directory, run:

```powershell
npx expo start
```

Scan the QR code with Expo Go, or press `a` to open an Android emulator. The project is also available through `npm start`.

The browser concept source and assets are bundled into `src/signatureHtml.ts`; the Expo shell hosts it in a native WebView and provides safe-area and Android back-button handling.
